# Triage labels

Use these values in a ticket's `Triage:` field. Lifecycle status and wayfinder type are separate fields.

| Canonical role | Local label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Fully specified; an agent can work independently |
| ready-for-human | ready-for-human | Requires human work |
| wontfix | wontfix | Will not be actioned |
